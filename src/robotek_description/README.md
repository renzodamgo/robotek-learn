# robotek_description

URDF/xacro of the Robotek WRO 2026 car (`urdf/robotek.urdf.xacro`) and RViz
configurations (`rviz/`). Shared by the simulation (`robotek_gazebo` spawns it) and
the real robot. Car and sensor measurements used by the strategies live in
`robotek_common/vehicle.py` and must match this URDF.
